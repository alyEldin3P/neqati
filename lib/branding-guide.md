# Neqati App Branding Guide

## Brand Overview

Neqati (نقاطي) is an Arabic loyalty points app designed for contractors, engineers, and technicians in the construction industry. The name "Neqati" means "My Points" in Arabic, emphasizing the personal ownership of rewards earned through the app.

## Brand Values

- **Trust**: Building reliable relationships with users
- **Reward**: Recognizing and appreciating user loyalty
- **Simplicity**: Creating an intuitive user experience
- **Professionalism**: Catering to construction industry professionals

## Logo

The Neqati logo combines Arabic calligraphy with modern design elements:
- Primary logo: Stylized "نقاطي" text with an accent point symbol
- App icon: Simplified point symbol in the primary color
- Clear space: Maintain padding of at least the height of the point symbol around the logo

## Color Palette

### Primary Colors
- **Deep Teal** (#006064): Main brand color representing trust and professionalism
- **Gold Accent** (#FFD700): Represents rewards and achievement

### Secondary Colors
- **Light Teal** (#4DD0E1): Used for UI elements and backgrounds
- **Neutral Gray** (#607D8B): For text and secondary elements
- **Soft White** (#F5F5F5): Background color for content areas

### Functional Colors
- **Success Green** (#4CAF50): For positive actions and confirmations
- **Alert Red** (#F44336): For errors and warnings
- **Information Blue** (#2196F3): For informational messages

## Typography

### Arabic Typography
- **Primary Font**: "Cairo" - A modern Arabic font with excellent readability
- **Heading Font**: "Tajawal Bold" - For titles and important headings
- **Body Font**: "Cairo Regular" - For general text content

### Font Sizes
- **Large Title**: 24sp
- **Title**: 20sp
- **Subtitle**: 18sp
- **Body**: 16sp
- **Caption**: 14sp
- **Small**: 12sp

## UI Elements

### Buttons
- **Primary Button**: Deep Teal background with white text
- **Secondary Button**: White background with Deep Teal border and text
- **Disabled Button**: Light gray background with darker gray text
- **Button Radius**: 8dp rounded corners

### Cards
- **Standard Card**: White background with subtle shadow
- **Highlighted Card**: White background with Gold Accent border
- **Card Radius**: 12dp rounded corners
- **Card Elevation**: 2dp shadow

### Icons
- **Style**: Simple, outlined icons with 2dp stroke
- **Primary Icons**: Deep Teal color
- **Action Icons**: Gold Accent color
- **Size**: 24dp standard size

## Imagery

### Photography
- **Style**: Bright, professional images of construction sites and professionals
- **Treatment**: Subtle overlay of Deep Teal for brand consistency
- **Content**: Focus on people using construction materials and equipment

### Illustrations
- **Style**: Simple, flat illustrations with the brand color palette
- **Usage**: For onboarding, empty states, and educational content

## Voice and Tone

### Language
- **Primary Language**: Arabic
- **Direction**: Right-to-left (RTL)
- **Tone**: Professional yet approachable
- **Address**: Direct second-person ("you")

### Writing Style
- **Clear**: Avoid technical jargon unless necessary
- **Concise**: Keep messages brief and to the point
- **Helpful**: Focus on guiding the user
- **Positive**: Emphasize rewards and benefits

## App-Specific Elements

### QR Code Design
- **Style**: Custom QR codes with the Neqati point symbol in the center
- **Colors**: Deep Teal and white for high contrast and scannability

### Level Badges
- **Style**: Circular badges with increasing embellishment for higher levels
- **Colors**: Progress from Light Teal to Gold for highest levels

### Points Display
- **Style**: Prominent display with Gold Accent color
- **Animation**: Subtle animation when points increase

## Accessibility

- **Text Contrast**: Maintain WCAG AA standard minimum contrast ratio (4.5:1)
- **Touch Targets**: Minimum size of 44dp x 44dp for interactive elements
- **Color Independence**: Do not rely solely on color to convey information
- **Text Scaling**: Support font scaling up to 200% without loss of functionality

## Implementation Guidelines

- Use the provided color constants in the app's theme configuration
- Maintain consistent spacing using 8dp grid system
- Follow RTL best practices for all layouts
- Ensure all UI elements adapt appropriately to different screen sizes
